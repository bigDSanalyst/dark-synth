# A4 — Boundary Adversary

**Claim.** Theorem 3.6(2)
**Failure mode.** FM4 (residual case)
**Bug.** Plain Vandermonde rank fails on lacunary exponents (boundary chain ℓ₀ < ... < ℓ_D need not be consecutive after Frobenius).
**Caught by.** Prefix-sum pigeonhole: with r ≤ D evaluation points and D+1 prefix sums, two must be congruent mod r, forcing target-on-seed aliasing.
**Fix.** The boundary adversary `τ_s = -α_s^{a_s} x_s` zeroes the s-th factor of the s-th summand for every s ≤ r, so the summand is identically zero while the target is `c_{a*} γ_{a*} ≠ 0`.
